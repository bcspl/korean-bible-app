## 3. 데이터·라이선스 (검증 기준)

### 3.1 성경

| 역본 | 절 수 | 출처·성격 | 검증 |
|------|-------|-----------|------|
| **KRV** 개역한글 | 31,101 | 성경전서 개역한글판(대한성서공회) PD · holybible 수집(`crizin/bible-db`) | 빈 절 0, 장 수 정합, 골든 구절 PASS |
| **KJV** | 31,102 | seven1m/open-bibles `eng-kjv.osis.xml` | 원본 재파싱 text_diff=0 |
| **ASV** 1901 | 31,102 | open-bibles `eng-asv.zefania.xml` | 원본 재파싱 text_diff=0 |

- 자동화: `python scripts/verify_bible_texts.py` → **RESULT: PASS**
- KRV↔KJV **절 번호 5곳** 차이는 한·영 versification 차이(정상), UI는 없는 절을 `—` 처리
- Hive `data_revision=2026-08-10-holybible-pd` 로 완전본 재시드

### 3.2 찬송 · 교독 · 기도

- 찬송: `scripts/build_pd_hymn_catalog.py` → `assets/data/hymns.json` (102)
- 교독: 구절 **참조**만 저장, 런타임에 선택 역본으로 본문 생성 (`responsive_readings.json` 51)
- 기도: `lib/data/worship_texts.dart` — 주기도문은 **마 6 서사 제외·기도문만**

## 6. 사용자 관점 — 사용성·가치 권장사항

아래는 **추가 개발 제안**이며, 우선순위는 사용자 가치 대비 노력으로 정렬했다.

### 6.1 즉시 체감 (High value / 중간 노력)

1. **첫 실행 온보딩 1화면**  
   “오프라인 · PD · 개역한글 기본 · 영어 KJV/ASV 병렬”을 3줄로 설명. 신규 사용자가 역본 칩 의미를 바로 이해.
2. **역본 선택 기억**  
   `SharedPreferences`로 마지막 활성 역본 세트 저장. 매번 KRV+KJV로 리셋되는 마찰 제거.
3. **절 공유 / 복사**  
   롱프레스 → “KRV만 / 선택 역본 모두 복사·공유”. 소그룹·카톡 사용 시 가치 큼.
4. **글자 크기 제스처**  
   본문 핀치 줌 또는 플로팅 ±. 시니어 사용자가 설정 탭을 안 열어도 됨.
5. **교독문 “인도자만 / 회중만” 강조 모드**  
   실제 예배 때 태블릿을 인도자가 들 때 가독성 향상.

### 6.2 신뢰·안전 (가치 = 법적·심리 안심)

6. **라이선스 한눈에 보기 화면**  
   설정/이 앱에 대해서: KRV·KJV·ASV·찬송·교독 출처 표, “개역개정·새찬송가 교독 미포함” 명시.
7. **본문 검증 배지**  
   “verify_bible_texts PASS · 2026-08-10”을 개발자용이 아니라 설정 하단에 약식으로.
8. **스토어 전 패키지 ID·서명**  
   `com.example.*` 제거, 프로덕션 키스토어, 개인정보처리방침 URL — **배포 가치의 병목**.

### 6.3 읽기 경험 심화 (High value / 큰 노력)

9. **통독·읽기 계획**  
   90일/1년 계획, 체크, 로컬만 저장. 재방문 동기.
10. **최근 본 위치 복원**  
    마지막 책·장·절 자동 복귀.
11. **하이라이트 색 (로컬)**  
    북마크와 별도, 색 3종 — 학습·묵상 사용자.
12. **TTS (선택)**  
    기기 TTS + KRV 우선. 운전·설거지 중 청취. (품질·언어 이슈 있음)
13. **한·영 절 대조 레이아웃 옵션**  
    세로 스택(현재) vs 좌우 2열(태블릿).

### 6.4 찬송·예배

14. **찬송 카테고리 필터** (찬양/회개/성탄 등) — 데이터에 category 이미 있음.  
15. **교독문 + 관련 찬송 링크** (선택).  
16. **공식 악보는 PARKED 유지** — PD 스캔·자체 제판 전제 시에만 재개.
