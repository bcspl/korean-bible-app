## 앱 제목
한국어 성경 - 개역한글·찬송가·교독문

## 한 줄 설명
광고 없이 오프라인으로 읽는 개역한글 성경. KJV·ASV 대조, 찬송가 102곡, 교독문 51편까지 한 앱에.

## 상세 설명
인터넷 연결 없이 언제 어디서나 읽을 수 있는 무료 성경 앱입니다.
광고가 없고, 회원가입도 없으며, 어떤 개인정보도 수집하지 않습니다.

■ 성경 읽기
· 개역한글(KRV) 신구약 66권 전체 수록
· 영어 역본 KJV(King James Version), ASV(American Standard Version) 함께 제공
· 역본을 골라 한 화면에서 나란히 대조해 읽기
· 책 이름 검색과 본문 검색
· 이전 장/다음 장으로 이어 읽기

■ 찬송가
· 저작권이 만료된 퍼블릭 도메인 찬송 102곡
· 한글·영어 가사, 작사·작곡자, 곡의 유래와 역사
· 악보 보기, 즐겨찾기, 제목·가사·작사·작곡 검색

■ 예배 자료
· 교독문 51편(시편·성탄·부활·이사야·누가 등), 인도자/회중 구분 표시
· 주기도문, 사도신경 (개역한글·KJV·ASV)

■ 북마크
· 마음에 남는 구절을 저장하고 바로 다시 열기

■ 읽기 편한 화면
· 다크 모드
· 글자 크기 조절
· 고대비 모드

■ 개인정보와 오프라인
· 모든 본문과 자료가 앱 안에 들어 있어 데이터 없이 동작합니다.
· 인터넷 권한을 사용하지 않습니다.
· 북마크, 즐겨찾기, 화면 설정은 기기 안에만 저장되며 외부로 전송되지 않습니다.

■ 저작권 안내
수록된 성경 역본(개역한글·KJV·ASV)과 찬송가는 모두 저작권 보호 기간이 지난 퍼블릭 도메인 자료입니다.

## 검색 키워드 (10개)
성경, 개역한글, 찬송가, 교독문, 오프라인성경, 무료성경, KJV, 주기도문, 사도신경, 영어성경
